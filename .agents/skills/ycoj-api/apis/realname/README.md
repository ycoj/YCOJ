# Real-name verification

Logged-in users who are not a super administrator (`priv === -1`) or a judge service account must submit a real name and school. The seven-day grace period starts at the user’s first application (`realnameSubmittedAt`, falling back to the earliest application `submittedAt` when the user field is missing). During that window, `pending` and `rejected` users may use ordinary site features. Updating a pending application, rejecting, revoking, or resubmitting does not reset the clock. After seven days, if the latest application is still not `approved`, HTTP handlers other than the allowlisted account/auth/realname/utility routes and public versioned UI assets (`/lazy/:version/:name`, `/resource/:version/:name`, `/plugins/:version/:name`) return `RealnameRequiredError` and redirect to `/home/realname` or `/home/realname/result`. Super-admin `revoke` keeps `realnameSubmittedAt`; if the original window has already elapsed, the user is locked immediately, and a later resubmit does not start a new window. WebSocket handshake does not throw `RealnameRequiredError`; the `/websocket` subscription gateway rejects profile users who are neither approved nor within the grace period unless the connection is a privileged gateway.
